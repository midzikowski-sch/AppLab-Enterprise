# AppLab Enterprise Landing Page Project

## Business Identity
* **Business Name:** AppLab Enterprise
* **Service:** Personalized AI App Creation Services for B2B clients
* **Target Audience:** Businesses seeking custom AI applications without managing in-house development teams.
* **Unique Value Proposition (UVP):** Leveraging top-tier talent from the AppLab global thinktank, commission-driven motivation, and AI-native expertise.

## Color Palette
* **Background (Primary):** Gunmetal Black - `#1D1D1D`
* **Secondary/Text:** Quicksilver - `#E9E9E9`
* **Accent (Headers/Icons):** Aqua Blue - `#00D3E2`
* **Accent (CTA Buttons):** Lab Green - `#00EFBC`

## User Story
**As a** business owner visiting the site, **I want to** easily find the "Book a Discovery Call" button, **so that** I can initiate the process of having a custom AI app built for my company.

**Implementation:** The page features prominent "Let's Talk," "Book a Discovery Call," and "Get a Free Estimate" buttons styled with the high-contrast Lab Green (`#00EFBC`) accent color. This makes them immediately visible against the Gunmetal Black background, serving as clear Call to Actions (CTAs) that direct the user to the contact and booking phase.
